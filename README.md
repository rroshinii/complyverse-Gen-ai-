# 🚀 ComplyVerse

> **Autonomous Compliance Intelligence Platform**

ComplyVerse is an AI-powered compliance intelligence platform that helps organizations streamline regulatory management by transforming complex compliance documents into actionable insights. It leverages artificial intelligence to automate document analysis, identify compliance risks, generate knowledge graphs, simulate policy impacts, and provide explainable recommendations for informed decision-making.

---

## ✨ Key Features

* 📄 AI-powered compliance document analysis
* 🤖 Intelligent regulatory knowledge extraction
* 🧠 Dynamic compliance knowledge graph generation
* ⚠️ Automated compliance risk identification
* 📊 Interactive compliance dashboard
* 🔍 Smart search across uploaded documents
* 📁 Multi-format document support (PDF, DOCX, CSV)
* 💬 AI-powered compliance assistant
* 📈 Policy impact simulation
* 📤 Knowledge graph export
* 🔐 Secure environment-based configuration
* ⚡ Fast and responsive user experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone <repository-url>
cd complyverse
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root.

```env
GEMINI_API_KEY=your_api_key
```

Add any additional environment variables required by your deployment environment.

### Start Development Server

```bash
npm run dev
```

---

## 📦 Production Build

Build the application:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
